# Rebecca Desktop Companion

**Концепция 0.2 — 26.10.2026.** Красивый, автономный и полезный 2D-компаньон для Windows, вдохновлённый Ребеккой из Cyberpunk: Edgerunners. Язык интерфейса и документации — русский. Целевая платформа — Windows 11; Windows 10 требует отдельной проверки.

**Сейчас работает графический прототип.** Полноценные поведение, эмоции, память и инструменты ниже — план развития, а не уже доступные возможности. Python-пакет пока имеет версию 0.1.0. В этой ревизии обновлена только документация; рабочий код, кадры и зависимости не меняются.

## Направление проекта

Порядок приоритетов: **визуальное качество → автономность → полезные функции → общение**.

Ребекка должна восприниматься как небольшой живой персонаж с характером, занятиями и настроением, помогая с повседневными задачами. Основа — подготовленная детализированная 2D-графика, качественная покадровая анимация, портреты и аккуратный неоновый интерфейс. Примитивные программные спрайты не заменяют художественные материалы. Сторонние наборы используются при наличии подходящих прав.

Поведение строится на локальных FSM/utility-правилах, общение — на сценарных репликах. Программа работает **без интернета и моделей**. Codex пишет код, но не работает внутри персонажа. Будущий DialogueProvider остаётся отдельным контрактом; реализации LLM, SDK и ключи сейчас не добавляются.

Не допускаются телеметрия, скрытый доступ к личным данным, управление чужими окнами, глобальные хуки и полноэкранный прозрачный слой. Персонаж не должен забирать фокус или блокировать соседние приложения. Фоновые возможности должны иметь настройки и понятный выключатель.

## Что уже есть

Аудит выполнен на базе `main` / `179dff0`:

- Компактное прозрачное окно без рамки, над панелью задач, поверх обычных окон.
- Перетаскивание, ограничение рабочей областью экрана, обработка изменения экранов.
- Меню «Пауза / Продолжить», «Скрыть / Показать», «Развернуть», «Выход» и системный трей. Без трея скрытие отключается.
- Одиночные PNG idle/walk/sleep/angry/happy/sit и подключённые циклы: idle — 12 кадров / 6 FPS, walk — 8 кадров / 8 FPS. Walk пока проигрывается на месте.
- Масштаб 1–4 через Nearest Neighbor, отражение, остановка графического таймера при паузе/скрытии. Настройки выбираются при запуске, между запусками не сохраняются.
- Fallback на одиночный PNG, затем на старую временную фигурку. --demo-animation явно показывает техническую заглушку, а не вашу Ребекку; не использовать эту команду как основной сценарий.
- 47 существующих автоматических тестов. Windows-пользователь подтвердил базовые окно, PNG, drag и меню/трей; полная матрица DPI/мониторов и свежие циклы кадров требуют своей проверки.

**Текущие ограничения:** PNG до 64×96, до 32 кадров в цикле, FPS 1–30; одинаковый холст кадров. Нет переключения клипов в работающем приложении, переходов, явной точки опоры, крупных портретов и темы. Прозрачные участки прямоугольника могут получать клики. Нет автоматических прогулок, FSM, эмоций как системы, памяти, таймеров пользователя, заметок, концентрации и диалогового провайдера. Нет EXE-сборки и измеренного бюджета ресурсов.

## Первая полезная версия U1 — предложение

U1 объединит качественный ограниченный арт-набор с переходами/портретами и компактной панелью, простые прогулки/ожидание/сидение/сон и управляемые параметры характера. Практическая часть: таймеры, одноразовые напоминания, текстовые заметки, часы и концентрация. Настройки, пользовательские записи и небольшое резюме взаимодействий сохраняются локально; сценарные темы работают без сети и провайдера модели.

Польза должна оставаться при отключённой автономности. Сложные привычки, прыжки, физика, музыка, взаимодействие с окнами и LLM — после U1 отдельными этапами. Состав и проверяемые критерии подробно описаны в SPEC; U1 не является ближайшей одной задачей.

## Установка и запуск текущего прототипа

Нужны Python **3.12, 64-bit** и Windows. Проверенные в облаке версии: Python 3.12.14, PySide6 6.10.2. Откройте PowerShell в папке проекта с pyproject.toml:

```powershell
py -3.12 -m venv .venv
./.venv/Scripts/python.exe -m pip install -e .
./.venv/Scripts/python.exe -m rebecca --state idle --scale 2
```

Активация окружения и изменение ExecutionPolicy не нужны. Интернет требуется для первоначальной установки зависимостей, а не для работы персонажа. После закрытия через «Выход» можно проверить walk:

```powershell
./.venv/Scripts/python.exe -m rebecca --state walk --scale 2
```

Ребекка меняет кадры на месте. --scale принимает 1–4 (по умолчанию 4); --facing left отражает исходник, right оставляет оригинал. Файлы не меняются. --sprites-dir задаёт другую папку PNG; animations.json тогда ищется на один каталог выше неё. Формат и требования — в инструкции к спрайтам.

Обновление уже слитой версии, если локальные изменения сохранены и нужна main:

```powershell
git fetch origin
git switch main
git pull --ff-only origin main
```

Не использовать reset/force для обхода конфликта локальных файлов. Пока PR не слит, проверять ветку, указанную в сообщении к этому PR: main ещё не содержит её изменения.

## Проверки и известные границы

```powershell
./.venv/Scripts/python.exe -m compileall -q src tests
./.venv/Scripts/python.exe -m unittest discover -s tests -v
```

В Linux без дисплея тесты запускаются с QT_QPA_PLATFORM=offscreen. Они проверяют логику Qt; доступность трея в части тестов подставляется. Они не доказывают нативную прозрачность, отсутствие мерцания, фокус, tray или DPI Windows. Целевые бюджеты CPU/памяти из SPEC пока не измерены.

Ручной сценарий текущего прототипа:

1. Обычный запуск idle, затем walk: показываются ваши кадры с прозрачным фоном, нет рамки, окно находится над панелью задач; walk не перемещает персонажа.
2. Перетаскивание и соседние клики работают; другое приложение принимает ввод. Пауза замораживает кадры и drag, продолжение возвращает их; отражение не сдвигает окно.
3. Скрытие и возврат через значок возле часов сохраняют позицию, направление и паузу. Значок может находиться в «Показать скрытые значки» Windows.
4. «Выход» из меню персонажа и из трея при скрытом персонаже завершает процесс. Отдельно проверить имеющиеся DPI и несколько мониторов; недоступные конфигурации отмечать как непроверенные.

Новые лимиты крупных PNG, переходы и полезные инструменты из SPEC **пока не поддерживаются кодом**. В этой задаче не нужно повторять установку или переписывать рабочий прототип.
