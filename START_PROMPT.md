# Первый запрос в Codex

Прочитай файлы `AGENTS.md`, `README.md`, `SPEC.md`, `ARCHITECTURE.md`, `ROADMAP.md` в корне этого проекта. Мы создаём автономную пиксельную Ребекку для рабочего стола Windows **без языковых моделей и без интернета**. Я новичок, поэтому работаем маленькими этапами и обязательно проверяем результат после каждого.

**Твоя задача сейчас — только первый минимальный прототип:**

1. Создай минимальный запускаемый Python-проект с PySide6, без лишних зависимостей и без усложнённой структуры.
2. Открой **небольшое** прозрачное окно без рамки (не полноэкранное), которое показывает временную пиксельную фигурку/PNG вместо готового спрайта Ребекки. Отрисовка должна сохранять чёткие пиксели.
3. Размести фигурку в видимой рабочей области основного монитора, выше панели задач.
4. Дай простой гарантированный способ закрыть программу: меню по правому клику с пунктом «Выход». Не добавляй полноценный трей, ходьбу, физику, эмоции и сохранения на этом этапе.
5. Не перекрывай весь экран невидимым окном. Не перехватывай глобально мышь и клавиатуру. Не подключай сеть или AI SDK.
6. Добавь короткие команды установки и запуска для Windows PowerShell.
7. Проверь то, что можешь проверить в текущей среде; отдельно обозначь, что пользователь должен проверить глазами на Windows.

**Критерий успеха:** я вижу маленькую тестовую фигурку без фона, могу работать с остальным рабочим столом и могу закрыть персонажа правой кнопкой.

После выполнения **остановись и не переходи к следующему этапу**, пока я не подтвержу, что всё работает. В конце расскажи простыми словами: что сделано, какие файлы затронуты, что запустить и что проверить.
